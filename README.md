# MountOrganizer
A World of Warcraft Retail addon for creating and managing arbitrary mount collections to be able to randomly spawn a mount based on a defined collection.

## Limitations

MountOrganizer requires the use of global macros per-account in order to provide the ability for an icon to be dragged to the action bar and be used to spawn a random mount from the defined collection.  This means that if the account has already the maximum number of global macros, one or more would have to be deleted in order to make room for this addon to properly work.  This is a limitation with how Blizzard set up the ability to create buttons to use on the action bars.
